# 结果与图表溯源规则

## 目标

证明论文中的每个关键数值、表格和图片可以追溯到明确的运行、代码版本、配置和输入。

## 最小溯源链

```text
论文结果项
  → 结果文件或记录
  → 聚合/绘图脚本
  → 原始运行日志或预测
  → 生效配置与随机种子
  → 代码提交与数据版本
```

## 检查要点

- 表格中的列名、单位、舍入和排序与生成逻辑一致。
- “best”“last”“average”等选择规则有代码和日志支持。
- 均值和标准差来自声明数量的独立运行，不是 batch 内统计。
- 图片不是手工拷贝后失去生成输入；绘图脚本能定位到来源文件。
- 结果目录没有混入不同分支、配置、数据版本或重复运行。
- 论文报告值允许的舍入误差需在矩阵中说明。
- 缺少原始日志时，不得仅凭最终 CSV 宣称完整复现。

## GitHub 发布建议

不要求公开受许可限制的数据或超大 checkpoint，但仓库必须清楚说明获取方式、校验标识、目录约定和运行命令。敏感数据、凭据和本机路径属于发布阻断项。
