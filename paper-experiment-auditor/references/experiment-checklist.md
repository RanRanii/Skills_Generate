# 实验一致性检查清单

按论文中实际存在的声明选择检查项，不要求每个项目都具备全部条目。

## 数据

- 数据集名称、版本、下载来源和许可说明
- 样本纳入/排除规则和去重
- 训练、验证、测试划分及随机性
- 预处理、标准化、增强、tokenization 和缓存
- 标签生成、缺失值处理和数据泄漏
- 论文样本数量与代码实际统计

## 模型与方法

- 模型组件、层数、维度和连接关系
- 公式与实现的运算顺序、归一化和符号
- 损失项、权重、mask、reduction 和正则化
- 预训练权重、冻结策略和初始化
- 推理阶段与训练阶段差异

## 训练与配置

- 优化器及参数
- 学习率、warmup、scheduler 和衰减
- per-device batch、梯度累积和总 batch
- epoch、steps、早停和保存频率
- 最佳 checkpoint 与最后 checkpoint 的选择
- 混合精度、梯度裁剪和分布式设置
- 默认值、配置文件、CLI 与环境变量覆盖关系

## 评价指标

- 公式、库实现及版本
- 指标输入是 logits、概率、类别还是连续值
- macro、micro、weighted、per-class 和样本聚合
- 越大越好或越小越好
- 阈值、后处理和无效样本处理
- 单次、最佳次、均值或中位数

## 对比与消融

- baseline 是否使用相同数据、划分和评价流程
- 训练预算、预训练资源和调参机会是否公平
- 消融开关是否从真实执行图中移除目标模块
- 组合消融是否与表格列名对应

## 随机性与重复

- Python、NumPy、框架、CUDA 和数据加载器随机性
- seed 是否在关键对象创建前设置
- 独立运行次数和 seed 列表
- 均值、标准差或置信区间计算

## 结果与发布

- 结果文件与论文表格/图片的映射
- 日志、checkpoint 和绘图输入是否来自同一运行
- README 命令是否实际存在且使用发布配置
- 环境锁定、数据准备、模型获取和评估说明
- 是否含绝对路径、私有依赖、密钥、个人数据或未提交文件引用
